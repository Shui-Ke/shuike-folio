# 场景编辑器

双击项目里的 `Scene-Editor.cmd`，浏览器会打开编辑器。如果此项目的编辑器已经运行，重复双击只会打开现有页面，不会再启动一个服务。首次启动时请保留启动窗口；关闭该窗口会停止编辑器的本地保存服务。

1. 在左侧素材库按分类或名称找到模型，将卡片拖入地形。也可以先点击卡片，再点击地面放置。
2. 点击场景中的物件或右侧列表选中它，用顶部的移动、旋转、缩放工具调整；右侧可输入准确数值。
3. “贴合地形”将物件底部放到所在位置的地面上。“网格吸附”让放置位置按整米对齐。
4. 输入场景名称，点击“保存场景”。布局会保存在项目的 `editor-scenes` 文件夹中。下次通过“打开”继续编辑。
5. 布置完成后，把场景名称告诉我，我可以读取布局，为建筑、道路、道具分别设置合适的碰撞，并接入游戏。

左键拖动空白处环绕，Shift＋左键或右键拖动平移，滚轮缩放。Shift＋左键在地形笔刷模式下同样有效，只平移视角，不修改地形。选中物件后，W / E / R 切换移动、旋转、缩放；F 聚焦；Delete 删除；Ctrl+Z 撤销；Ctrl+Shift+Z 重做；Ctrl+S 保存。

左上角“底图”可以切换 Bruno 原版完整地图、峡谷、平地或自建地形。Bruno 使用原版游戏渲染，原有场景物件锁定，新增素材可以移动、旋转和缩放。切换底图保留新增物件，地形高度有差异时请用“贴合地形”。切换前先保存当前场景；“打开”用于切换已保存的地图。

点击“新建地图”，输入名称和边长，创建空白地形。左侧浮动笔刷面板支持升高、降低、平滑和平整；选好工具后左键按住涂抹，右键平移，滚轮缩放。“选择 / 环绕”回到物件编辑。平整使用面板中的指定高度。每次按下到松开算一次操作，可撤销和重做。

“种草”和“擦除草地”编辑草地范围；编辑时显示地面颜色，驾车试玩时使用原版 Grass 动态草叶。“开挖河流 / 湖泊”按笔刷半径挖低地形并添加水面，拖动可画河道；设置水位和河床深度控制效果。“擦除水面”保留已经挖出的河床，可用平整或升高填回。水位是整张地图共用的，暂不支持瀑布和多个不同高度的湖泊。

道路分类中的“朱红大桥”是独立模型，包含桥廊和底部承重拱门，不包含峡谷及引道。放置高度以桥面为准，适合放到挖出的河谷上；需要时调整 Y 高度与两岸对齐。山体、玄武岩、其他建筑与道具均可组合摆放。

点击“驾车试玩”使用原版车辆和游戏渲染测试当前地图。WASD 驾驶、Shift 加速，Esc 或“返回编辑”回到编辑器；自建地图按 R 返回试玩出生位置。地形与新增模型会生成临时三角网格碰撞，桥洞保持开放；正式接入游戏前仍可由助手简化碰撞、设置特殊物件行为。试玩位置不会改写布局，保存布局也不会覆盖原版游戏地图。

布局文件包含自建地形高度、草地、水域和物件变换。浏览器会保留草稿，但仍应点击“保存场景”写入项目。“导出布局”下载 JSON 备份，“导入布局”打开备份。原版地图目前作为锁定底图，地形笔刷用于“自建地形”。

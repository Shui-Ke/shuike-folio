# 黄沙废土素材库

此素材库包含 Bruno 原生素材的整理版和新增的废土模型。

`道具/` 内每个 GLB 只有一件完整道具，并有一个同名顶层节点。模型已居中、底部对齐地面，可整件拖入场景。灯体、灯罩和门锁等部件保留在道具内部，碰撞参考节点标记为 `collisionReference`。

原生长椅、砖块、木箱、木栅栏、灯笼和路灯内嵌调色板贴图。游戏还会在运行时替换灯光等材质。`灌木_参考`、`花丛_参考` 仅含单个摆放参考体，具体植物形状和颜色由游戏代码生成。

## 道路拼接

`道路/` 下的直行道、90° 弯道和 180° 掉头道直接裁自原赛道网格。三段路的行车面宽约 10 米，两侧各有 0.45 米宽、0.14 米高的红白路缘石。原点在入口中心，+Y 朝上，入口行进方向为 +Z。把下一段的 `Entry` 对齐上一段的 `Exit`（含旋转）即可拼接。几何体和材质可以直接导入 Blender 或 Three.js，碰撞体由使用场景配置。

## 使用方式

### 1. Blender 直接摆

- 打开对应 `.glb`
- 把模型拖进 `wasteland.blend`
- 视觉模型放在 `wastelandVisual`
- 碰撞代理放在 `wastelandPhysical`
- 碰撞体子物体按 `Objects.js` 的命名规则命名：

```text
trimeshTerrain
cuboidRock01
hullCar
tubePole
ballRock
```

### 2. 代码里加载

```js
[ 'waselandProp', `wasteland/library/道具/长椅.glb`, 'gltf' ],
```

实际使用时路径为：

```text
/wasteland/library/道具/长椅.glb
```

中文文件名在浏览器里会自动做 URL 编码。如果遇到加载失败，检查 Network 面板里的实际请求 URL。

## 注意

- `_碰撞参考` 主要是碰撞/摆放参考，不一定适合作视觉模型。
- 树木不要用整棵树做碰撞，只用树干圆柱/胶囊。
- 岩石/地形优先用简化碰撞网格，不要直接拿高模做 `trimesh`。
- 车辆可以用盒形碰撞，细节轮子不单独碰撞。
- 所有模型的坐标原点最好统一在地面中心。

# 自然地图 · 汽车混战

保留没有高楼的原始自然地形地图，以及玩家车辆、蓝/黄/紫三辆人机、物理碰撞、绕障追逐、脱困恢复和环境效果。

地图水平面积扩大到原来的两倍（长、宽各约 1.414 倍），沿用现有风格补充了 56 棵树、24 组灌木、24 个爆炸箱和 48 块砖，草地随地形延展，并留出穿行空间。西侧新增湖泊，浅岸可行驶，湖心深约 8 米；水面完全淹没车身时立即损坏，可按 R 复活。湖泊深水边界同样设有上升淡出的白色警示带。

玩家和人机的车辆外观、车轮、悬挂尺寸与碰撞体统一放大到 1.25 倍，道具碰撞范围与沉水检测同步适配。运行 `npm run test:map` 验证地图面积、物件数量、湖岸安全、湖心损坏及车辆尺寸。

## 开始游戏

双击 `Play.cmd`，打开已构建的游戏。首次安装依赖使用 `npm install`；修改源码后运行 `npm run build`，再重新打开游戏。开发时运行 `npm run dev`。

| 操作 | 功能 |
| --- | --- |
| W / A / S / D | 驾驶 |
| Shift | 加速 |
| Space | 跳跃、翻身 |
| ← / → | 切换当前道具（转向使用 A / D） |
| E | 使用当前道具 |
| 鼠标滚轮 | 调整相机远近 |
| R | 重生 |
| Esc | 设置 |

相机通常以固定俯视方向跟随车辆，滚轮缩放范围为 8–60，初始距离为 30。重击击飞时暂时拉远取景，结束后恢复到滚轮设定的距离，镜头朝向保持固定。打开设置期间暂停人机。

地址加入 `?bots=0#skip` 可切换到单车模式。外围海床已加深；水面完全淹没车身（不计天线）时，车辆爆炸并散落零件，玩家按 R 在出生点复活，人机损坏后留在淘汰状态。尚未加入撞击耐久与整局胜负结算。

外围深水边界设有简约白色警示带，细线分层上升并逐渐淡出，只作视觉提示，不阻挡车辆。岸边地面与泡沫边缘已细化，避免大块三角形白色缺口。

## 首版强化玩法

地图布置 POWER+、SPEED+、JUMP×2 各五个拾取点，玩家和人机共用规则。所有 buff 和道具模型在上一版基础上再放大 30%（相较初版累计约 60%），旋转动画速度加快 10%，周围带有错落闪烁的浅色四角星光与淡光环；每 30 秒在整座岛屿的安全陆地上重新随机布置一批，未拾取的道具也会换位置，避开水域、固定障碍和车辆附近。满级 buff 仍可拾取并消失，但不会再增加属性。玩家 R 复活后强化重置。

- POWER+：五次强化，倍率从 1 依次提升到 2、3、4、5、6。车头或车尾主动撞中对方时获得额外推力，持续顶住不会逐帧重复结算。车尾撞击也按同样阈值触发爆炸与击飞，击退方向沿实际撞击方向。
- SPEED+：两次强化，实际行驶速度为基础的 1.5、2 倍；速度白值从基础的 1–5 对应提升至 1.5–7.5、2–10。
- 重击：最终 POWER 数值 × 最终速度白值 ≥ 4 时触发。理论击飞距离 = 50 × min(力量×速度 / 30, 1) 米；例如强度 6、15、30 分别对应 10、25、50 米。弧线高度随强度增长，最低 3 米、最高 12 米，配合弧线拖尾、短暂慢放、现有爆炸效果和镜头拉远；爆炸仅作视觉表现，不产生额外冲击力。实际落点会受到地形或障碍物碰撞影响。未达阈值时保留普通碰撞，并按强化增加推力。
- JUMP×2：一次拾取开启二段跳，每次落地后恢复。Space 按下触发一次，长按不会连跳；空中保留惯性，并可作最高约起跳速度 25% 的方向调整（原地跳采用基础行驶速度的 25%）。键盘跳跃不显示触屏摇杆动画。

运行 `npm run test:gameplay` 可验证拾取、等级上限、实际提速倍率、车头碰撞、重击阈值、抛物线射程、纯视觉爆炸、镜头恢复及跳跃规则。

## 消耗道具

玩家与人机开局各有铁蒺藜、导弹、爆炸箱、护盾、喷气背包各 3 个。地图上可继续拾取，每种最多携带 9 个，拾取点随每 30 秒的随机刷新重新分布，每种维持 5 个，暂停时停止刷新计时。底部显示数量与当前选择，左右方向键切换、E 使用；手机直接点击对应道具按钮使用。空库存、暂停、车辆损坏或无法放置时不消耗数量。R 复活恢复试玩初始库存并清除自身的道具状态和已放置道具。

- 铁蒺藜：在车后放置，接触车辆立即归零速度，随后 15 秒行驶速度减半；一次触发后消失。
- 导弹：从车顶附近低速发射，随后匀加速；锁定发射时最近的其他存活车辆，以目标车身同色的圆环标记，绕向车尾低空追逐。尾部喷出低多边形黑烟，烟团膨胀、上浮并淡去，爆炸后残留烟雾自然消散。追踪 10 秒后直飞；击中车辆或场景会爆炸并产生范围推力，未命中则在 14 秒后清理。
- 爆炸箱：在车后放置，短暂布防后被车辆触碰引爆。与地图现有箱子保持同类外观和爆炸效果。
- 护盾：环绕车身显示上升淡出的白色警示条纹，外层隐形碰撞体阻挡车辆，免疫 3 次独立撞击或道具攻击；持续顶住只计一次，三次用尽后消失。持盾主动撞人可正常触发击退与重击，主动进攻不消耗次数；受到其他车辆撞击时保留自己的运动，不被对方推动。不会免疫溺水。
- 喷气背包：立即用气流推开周围 9 米内的车辆并升空，喷气持续 1.2 秒；期间可主动跳跃一次，拥有 JUMP×2 时可跳两次。从喷气升空到落地均可用 WASD（手机摇杆）自由前后左右移动，按当前 SPEED 等级与 Shift 加速状态计算空中速度，松开方向会降低水平速度；落地后恢复普通跳跃的空中操控规则。

人机会按距离选择使用道具。箱子和铁蒺藜从落点上方 2.2 米处下落，动画约 0.55 秒，落地再等 0.15 秒开始布防；放置者有 1.4 秒离开时间，60 秒未触发则清理。道具使用间隔 0.45 秒；护盾或喷气仍生效时不会重复消耗同类道具。运行 `npm run test:items` 验证道具行为、低空匀加速追尾、下落动画与电脑、手机输入。

导弹、放置爆炸箱和地图爆炸箱炸翻车辆后，自动翻身额外延后 2 秒：玩家由 3 秒变为 5 秒，人机由 1.5 秒变为 3.5 秒。刚被炸翻的前 2 秒也无法通过手动翻身提前起身；普通翻车不受影响。护盾成功挡下爆炸不会附加延迟，复活会清除该状态。

## 道具模型预览

双击 `Preview Props.cmd` 可打开七款道具的独立预览，支持拖动旋转和滚轮缩放。总览图保存在 `previews/powerups.png`。

`static/models/powerups/` 包含七个独立 GLB：`caltrop.glb`（纯深灰铁蒺藜）、`missile.glb`（导弹）、`jetpack.glb`（喷气背包）、`shield.glb`（灰色护盾）、`power-plus.glb`（POWER+）、`jump-times-two.glb`（JUMP×2）、`speed-plus.glb`（SPEED+）。均采用低多边形造型、独立零件和纯色材质，原点位于底面中心，Y 轴向上。七款均已接入玩法，爆炸箱复用地图模型。

造型源文件为 `sources/Models/PowerupModels.js`，运行 `npm run build:props` 可重新导出，再运行 `npm run build` 更新预览。

## 保留的目录

- `sources/`：驾驶、人机、物理、固定相机、地图及设置界面源码。
- `static/`：地图和车辆实际使用的模型、贴图、声音、字体及解码器。
- `dist/`：当前可试玩版本，由 `npm run build` 生成。
- `tests/`：核心运行验证，运行 `npm run test:core`；需本机 Chrome 和 Playwright。
- `node_modules/`、包清单及 Vite 配置：运行和构建依赖。

编辑器、高楼关卡、素材制作源文件、旧脚本和未使用资源已移至同级 `../bruno-archive-2026-11-08/`，其中保留了移动清单和修改前的源码快照。
